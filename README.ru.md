# 📋 Матрица задач и критичности IT-проекта (Печатный А4)

Минималистичный, экономный к тонеру веб-шаблон матрицы задач и критичности на 4 языках для **Frontend (Клиентская часть / UI)** и **Admin & Backend (API, БД, RBAC и Сервисы)**. Разработан для четкой черно-белой печати на листах А4, экспорта в PDF и интерактивного управления в браузере.

## ✨ Возможности

- 🖨️ **Оптимизация для ч/б печати А4:** Калибровка под размер 210 × 297 мм (`@page { size: A4 portrait; margin: 0; }`). Тонкие контрастные линии без сплошных заливок для экономии чернил и тонера.
- 🌐 **Поддержка 4 языков (i18n):** Мгновенное переключение интерфейса в один клик между **Русским**, **English**, **Türkçe** и **Azərbaycan dili**.
- ✏️ **Редактирование в браузере:** Все названия задач, описания, имена ответственных, оценки и метаданные проекта редактируются прямо на странице.
- 💾 **Автосохранение (LocalStorage):** Данные не сбрасываются при перезагрузке или закрытии вкладки.
- 📦 **Импорт и экспорт в JSON:** Сохраняйте планы спринтов в файлы `.json` и легко делитесь ими с коллегами.
- 📑 **Режимы отображения:**
  - **Все (2 страницы):** Стр. 1: Frontend | Стр. 2: Admin & Backend.
  - **Только Frontend:** Печать отдельного листа для клиентской команды.
  - **Только Admin & Backend:** Печать отдельного листа для серверной команды.
  - **[Компактная страница](tek_sayfa_kompakt.html):** Высокоплотная версия на один лист А4 для ежедневных стендапов.
- 🎯 **Цикл изменения приоритета:** Клик по бейджу (`P0`, `P1`, `P2`, `P3`) переключает уровень срочности.
- ✍️ **Режим пустого листа:** Переключение в режим с пунктирными линиями для ручного заполнения ручкой после печати.
- 🔤 **Шрифты Medeo:** Локальные пакеты вариативных шрифтов `Medeo Sans`, `Medeo Sans Display` и `Medeo Mono`.

## 🚦 Шкала критичности (Priority Matrix)

| Бейдж | Критичность | Описание и область | Срок реакции (SLA) |
| :---: | :--- | :--- | :--- |
| `[■ P0]` | **Блокер / Срочно** | Остановка продакшна, уязвимость auth, риск потери данных, основной процесс заблокирован. | Немедленно / В тот же день |
| `[▣ P1]` | **Высокий** | Обязательный функционал MVP, базовый CRUD, интеграция ключевых API. | Текущий спринт / 24–48 ч |
| `[□ P2]` | **Средний** | Второстепенные сценарии, валидация, мобильный адаптив, расширенные фильтры. | В плановом спринте |
| `[◌ P3]` | **Низкий** | Косметические правки, анимации, улучшения из бэклога (nice-to-have). | Бэклог |

## 🖨️ Руководство по печати

1. Откройте `index.html` (или [Онлайн демо](https://isihussain.github.io/it-task-matrix-a4/)) в Chrome, Edge или Firefox.
2. Выберите нужный язык (`RU`, `EN`, `TR`, `AZ`) и режим отображения.
3. Нажмите **"Печать А4 / В PDF"** или сочетание <kbd>Ctrl</kbd> + <kbd>P</kbd>.
4. Параметры печати:
   - **Принтер:** Ваш принтер или *Сохранить в PDF*
   - **Размер бумаги:** `A4`
   - **Ориентация:** `Книжная (Portrait)`
   - **Поля:** `Минимум / Нет`
   - **Фоновая графика:** `Включена`
